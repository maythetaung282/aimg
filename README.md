# AIMG Portfolio Website

Static portfolio site for **AI Myanmar Group (AIMG)** based on the company introduction PDF and Google Drive sample videos.

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npm start
```

Then visit http://127.0.0.1:8765

## What’s included

- Brand-aligned dark navy + cyan palette from the AIMG logo
- Company overview, services, education curriculum, VIP membership, seminar, and contact details from `회사 소개서.pdf`
- Clickable video samples from the Drive folders (LED ads + Premium Quality) plus PDF ad samples — open in an on-page player via Google Drive preview
